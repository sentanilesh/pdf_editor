## 1.0.0

* Initial release of `pdf_editor`.
* Full cross-platform support: Android, iOS, Web, Windows, macOS, Linux.
* High-performance viewing powered by PDFium / pdfrx.
* Multiple document sources: `bytes`, `file`, `asset`, `network`.
* Complete annotation suite:
  * Freehand drawing / pen
  * Semi-transparent highlighter
  * Text annotations with custom font size, styling, background, and borders
  * Shapes: Line, directional Arrow, Rectangle, and Oval/Circle
  * Digital handwritten signatures with dedicated signature pad dialog
  * Document stamps: `APPROVED`, `CONFIDENTIAL`, `DRAFT`, `REJECTED`, `URGENT`, `COMPLETED`, `VOID`, and custom stamps
  * Redaction / blackout boxes for sensitive information
  * Eraser tool
  * Selection and movement tool
* Page operations:
  * 90°, 180°, 270° page rotation
  * Page deletion
  * Page reordering
* In-document full text search with highlight matches and navigation.
* Page thumbnails sidebar.
* Full Undo / Redo history system.
* High-DPI PDF flattening export and direct system printing.
* JSON serialization and deserialization for annotation persistence.
* Included interactive cross-platform `example` application.
